Design rounds

How the visual direction of Ashen Contracts was chosen. The brief and the decisions are written down in docs/DESIGN.md; this page links the prototypes. Each one is static HTML and can be opened straight from disk.

Round 3: Reliquary, refined

Current direction

The Forge landing page leading into the Reliquary game screen: the whole loop (map, adventure, outcome, go again), location art above the event text, the energy orb with a regeneration countdown, an account menu, the character view, and a mobile layout with a bottom tab bar and a "More" sheet. The component sheet lists every part, its states and its tokens, and compares four colours for the primary button.
