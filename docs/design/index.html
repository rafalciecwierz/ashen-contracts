Ashen Contracts · docs/design

Design proposals

Four visual directions for the game UI, each showing the same two screens: the play screen at the Clearing (character, energy, an expedition in progress, the item-gated squirrel event, the chronicle) and character creation. Content follows GAME_DESIGN.md and the v0.1 specs; origin and trait names are placeholders. Static HTML, open each file directly in a browser.

A · recommended base

Chronicle

Three-column dashboard built 1:1 on design-tokens.json. Warm ash black, one ember accent, Cinzel + EB Garamond + Plex Mono.

B

Notice Board

Expeditions as paper contracts pinned to a board, sealed in wax when signed. Gives the game's name a visual meaning.

C

Embers

Text-first and almost chrome-less, after A Dark Room. Story log fades with age; action buttons fill as they cool down.

D

Manuscript

Light vellum theme: a book folio with margin notes, a rubricated drop cap and Roman-numbered choices.

Recommendation

  • Use A as the system: wire design-tokens.json into packages/ui/src/styles/theme.css, replacing the template's purple brand-* and Inter. It is the cheapest to build and scales to the stronghold.
  • Borrow from B for the contract board only: once GAME-01 settles that a contract is an expedition taken from a notice board, the board view and the wax seal for a signed contract can be one screen inside A, not the whole app.
  • Borrow from C for the narrative: the cooldown-fill button and the "newest line on top" story log fit the event feed in A's center column.
  • Keep D as A's light theme: it uses the same type family, so it is a token swap (data-theme="light"), not a second design.
