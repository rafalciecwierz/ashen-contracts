# Design

Visual design material for the game UI. Reference only: none of it is wired into the code yet.

- `design-tokens.json`: draft tokens (DTCG format) from the Chronicle mockup.
- `index.html`: overview of the four proposals below, with a comparison and a recommendation.
- `a-chronicle.html`: three-column dashboard built on `design-tokens.json`.
- `b-notice-board.html`: missions as contracts pinned to a notice board, a candidate look for the later contracts screen.
- `c-embers.html`: text-first, minimal, after _A Dark Room_.
- `d-manuscript.html`: light vellum theme, a candidate light mode for A.

Each proposal shows the same two screens (the play screen at the Clearing, and character creation) with content from `docs/GAME_DESIGN.md` and the v0.1 specs. Origin and trait names are placeholders. The mockups predate the GAME-01 decision (instant adventures for energy, choices later, navigation left and character right, see `docs/GAME_DESIGN.md`), so they show the visual language, not the final layout or mechanics. The files are static HTML: open them in a browser. They load fonts from Google Fonts.
